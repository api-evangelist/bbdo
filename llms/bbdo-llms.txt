# BBDO Worldwide

> BBDO Worldwide is a global advertising agency network founded in 1928 and headquartered in New York City, the largest creative-agency network inside Omnicom Group, with roughly 15,000 employees across ~289 offices in 81 countries. BBDO sells campaign work to brand clients — Pepsi, Budweiser, McDonald's, Mars/M&M's, Snickers, Visa, AT&T Business, Volkswagen — not software to developers. It publishes no developer portal, no OpenAPI, no SDKs, no pricing, and no status page. The one machine-readable surface it serves is the WordPress REST API behind bbdo.com, which is open for anonymous reads of the agency's case-study and press archive.

This file was generated by API Evangelist from the BBDO profile at https://apis.io/. It is not published by BBDO.

## What BBDO actually serves

- [WordPress REST API root](https://bbdo.com/wp-json/): Route discovery document, 200 routes across 10 namespaces. Real, live, anonymous. This is the CMS platform's API, not a product BBDO designed or supports.
- [wp/v2 namespace index](https://bbdo.com/wp-json/wp/v2): Per-route arguments and endpoint contracts.
- [Campaign work collection](https://bbdo.com/wp-json/wp/v2/work): 46 published case studies. `GET`, anonymous, paginated.
- [News collection](https://bbdo.com/wp-json/wp/v2/news): 60 published press items. `GET`, anonymous, paginated.
- [oEmbed provider](https://bbdo.com/wp-json/oembed/1.0/embed): oEmbed 1.0 for bbdo.com URLs.

## Reading it

- Pagination: `?page=` and `?per_page=` (max 100), with `X-WP-Total`, `X-WP-TotalPages`, and an RFC 8288 `Link` header carrying `rel="next"`.
- Sparse fields: `?_fields=id,slug,link,title`. Expansion: `?_embed`.
- Errors: WordPress envelope `{code, message, data: {status}}` as `application/json` — not RFC 9457.
- Auth: reads are open; writes require a WordPress Application Password issued from BBDO's own admin. There is no self-service registration.
- No rate-limit headers are returned. bbdo.com is behind Cloudflare bot management, which has served an HTML challenge shell to a bot user-agent on the same path that returned JSON to a browser user-agent.

## What does not exist

- No OpenAPI or Swagger — `/openapi.json`, `/swagger.json`, `/api-docs` all return 404.
- No GraphQL — `/graphql` returns 404.
- No MCP server, no A2A agent card — `/.well-known/agent-card.json` and `/.well-known/agent.json` both return 404.
- No `/llms.txt`, no `/.well-known/security.txt`, no OAuth or OIDC discovery — all 404.
- No SDKs or first-party packages on npm, PyPI, or any other registry.
- No pricing, plans, status page, changelog, deprecation policy, or developer support channel.
